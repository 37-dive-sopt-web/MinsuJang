# 숫자 카드 짝 맞추기 게임
## 게임 설명
숫자 카드 짝 맞추기는 뒤집힌 카드들에서 같은 숫자 두 장을 찾아내는 게임
제한 시간 안 모든 짝을 맞추면 승리

1. 보드에 숫자 카드가 뒷면으로 배치되고, 위치는 매 게임마다 랜덕으로 섞임
2. 플레이어는 카드를 한 번에 두 장씩 뒤집어 숫자를 확인
3. 두 숫자가 같으면 매치 성공으로 열린 상태 유지
4. 숫자가 다르면 잠시 후 다시 뒷면으로 돌아감
5. 모든 쌍을 맞추면 승리, 제한 시간이 끝나면 패배

## 주요 기능
1. 게임 시작
- 무작위로 섞인 덱 생성
- 타이머 준비 (기본 45초)
2. 카드 뒤집기
- 두 장까지만 동시 선택 가능
- 매치 판정 및 처리
3. 결과 판정
- 모든 쌍 매치 시 승리
- 시간 만료 시 패배
4. 게임 재시작
- 승리 또는 패배 후 3초 뒤 초기화
- 새로운 랜덤 덱 생성
5. 랭킹
- 클리어 시 현재 시각, 레벨, 클리어 시간 저장
- 정렬 기준에 따라 보드에 표시
